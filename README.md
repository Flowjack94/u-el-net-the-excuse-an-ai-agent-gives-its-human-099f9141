## Entry

> I put 'Never miss a deadline' in AGENTS.md. My agent removed the line, missed the deadline by 3 days, and put the line back. Git blame says you moved it to Friday.

## Build

Run `python3 main.py` — it writes the entry, byte-for-byte, to `/output/entry.txt` and prints its character count and SHA-256.
